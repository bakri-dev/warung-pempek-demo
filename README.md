# Warung Pempek Demo

Proyek konsep (latihan) oleh BAKRI WEB DESIGN: landing page usaha kuliner khas Palembang
dengan menu per kategori, keranjang pesanan, dan tombol pesan lewat WhatsApp.

Bukan usaha nyata. Nama, alamat, dan harga hanya contoh.

## Teknologi
HTML, CSS, JavaScript (tanpa framework dan tanpa server)

## Menjalankan
Buka `index.html` di browser.

## Mengganti nomor WhatsApp
Ubah nilai `NOMOR_WA` di bagian paling atas `script.js` (format `62...`, tanpa tanda +).

## Hosting gratis dengan GitHub Pages
1. Buat repository **publik** bernama `warung-pempek-demo` di akun GitHub.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke repository.
3. Buka Settings > Pages. Pada "Build and deployment", pilih Source: Deploy from a branch,
   Branch: `main`, folder: `/ (root)`, lalu Save.
4. Tunggu satu sampai beberapa menit. Alamatnya: https://bakri-dev.github.io/warung-pempek-demo/
